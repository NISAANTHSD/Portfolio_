# Nisaanth S D — Portfolio

Animated personal portfolio built with **React + Vite**, **Framer Motion** and **Lenis** smooth scroll.

## Run locally
```bash
npm install
npm run dev
```

## Edit content
All text, projects, skills, journey and certificates live in `src/data/profile.js`.
Resume and certificates are in `public/`.

## Deploy
- **Vercel:** import the repo — framework preset "Vite", build `npm run build`, output `dist`.
- **GitHub Pages:** `npm run build` and publish the `dist` folder (asset paths are relative).
